### 2.1 许可判断为何仍是“暂定”

- Kanripo GitHub 组织简介写明全部古籍集合以 CC BY-SA 4.0 提供。
- Kanripo 网站页脚写的是“All content created by us”采用 CC BY-SA 4.0。
- 但六个文本仓库本身均无 `LICENSE`，仓库 API 也没有许可证标识。
- 因而可进行不随包分发的内部试校；在许可主体和覆盖范围得到明确确认前，不复制候选全文到项目或候选 ZIP。

### 2.2 外字风险

六个仓库所用 `&KR...;` 编号都能在固定提交的 `KR-Gaiji` 找到，但多数只有字形图片，没有 Unicode：

- `KR3e0001`：26 种中仅 2 种有 Unicode；
- `KR3e0002`：14 种均无 Unicode；
- `KR3e0003`：2 种均无 Unicode；
- `KR3e0004`：8 种中仅 1 种有 Unicode；
- `KR3e0007`：8 种均无 Unicode；
- `KR3e0008`：9 种均无 Unicode。

因此“候选文本机器字符清洁”不能等同于“外字已解决”。试校中未知外字只作未知占位，不能因对齐时为空就判为脱字。

### 3.1 《素问》

- `恬淡虚无` / `恬惔虚无`：记一般异文，不改。
- `筋骨懈惰` / `筋骨解墮`：实质异文，须影像和第三见证，不改。
- `髮/髪`、`壽/夀`、`德/徳` 等只按字形差异处理。

### 3.2 《灵枢》

可疑点包括：

- 当前把篇题小注“法天”并入正文，候选只放在篇题；这是结构差异，不宜当普通脱衍处理。
- `收租税` / `收其租税`；
- `荣其逆顺出入之会` / `營其逆順出入之會`；
- `未呟其疾` / `未覩其疾`；
- 当前 `十二原各有所出`，候选作 `二原各有所出`，后者本身疑脱“十”。

这说明候选有价值，但不能机械覆盖当前本。

### 3.3 《伤寒论》

篇首三条只有一处规范化后实质差异：

- 当前：`阴阳俱紧者名为伤寒`；
- 候选：`隂陽俱緊者名曰傷寒`。

应待可靠宋本影像确认。成无己注文跨页后可能失去缩进，故只建议按当前条文锚点逐条比较，不建议全文自动剥注。

### 3.4 《金匮要略》

代表性异文包括：

- `补用酸` / `補用醋`；
- `千般疢难` / `千般灾難`；
- `针灸` / `鍼炙`；
- `实气相搏` / `實氣相傳`。

候选还有 `其目正圓者痊不治` 等明显可疑读法，且“湿伤于下、湿流关节”处用未释 `&KR0668;`，不能视为漏“湿”。本候选适合列差异，不适合直接订正文。

### 3.5 《难经》

- 当前《第一难》与 `KR3e0003` SBCK 经文完全一致。
- `KR3e0004` WYG 作 `脈之太會`，当前和 SBCK 作 `脈之大會`。
- 这正好证明异版本第三见证有用，也证明不能只凭多数或顺口裁决。

## 4. 王冰本 30 页码单元试跑

范围：`KR3e0001_001.txt`，SBCK `001-1a` 至 `001-15b`。

- 30 个页码单元；
- 356 个圆括号注文块，全部括号平衡；
- 括号外经文约 2687 个汉字，可稳定抽取；
- 37 个块出现“新校正”相关标记；
- 其中只有 6 个标记位于块首，31 个位于块中；
- 37 个块全部含斜线混排内容。

**决定：停止 Kanripo 王冰注全文重分层。**

圆括号足以分“经文/注文”，却不足以稳定分“王冰/新校正”。尤其斜线保存竖排栏序时，标记可能出现在块中或被拆成“新校/正云”。若强行自动切分，会制造错误作者归属。`KR3e0001` 以后只用于经文异文和页码锚定，不替换现有 Wikisource 分层。
