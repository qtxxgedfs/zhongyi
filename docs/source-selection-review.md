## 1. 结论摘要

- 六部原典均在中文维基文库找到可定位文本。
- 原计划28种独立作品中，Wikisource自动发现25种，未发现3种。
- 进一步复核发现一处错误匹配：程林《金匮要略直解》不能用周扬俊《金匮玉函经二注》替代。
- 为保证来源清楚并满足每部经典1—5种扩展，暂定首版为：
  - 原典6种；
  - 扩展/源流20种；
  - 合计26种独立作品。
- 作品“能找到”不等于文本“已校勘合格”。Wikisource多页明确标有25%、50%、校订不足、排版不佳或繁简转换错误，Phase 1必须保留质量标签并做自动与人工抽检。

### 3.2 替换

1. 马莳《黄帝内经素问注证发微》暂以张志聪《黄帝内经素问集注》替换。
   - 原因：前者未发现可审计的Wikisource全文，其他网络转录许可不明。
   - 张志聪本为原计划备选，Wikisource全文可取得，但标记为校订不足、排版不佳，需要强清理。
2. 马莳《黄帝内经灵枢注证发微》暂以丹波元简《灵枢识》替换。
   - 原因同上。
   - 《灵枢识》偏重汇校和辨析，与张志聪、张介宾互补。
   - Wikisource正文头部出现“丹波元珍”的元数据冲突，书内与通行书目题丹波元简；必须在来源记录中保留并说明冲突。

### 3.3 排除或延期

1. 程林《金匮要略直解》首版排除。
   - 搜索命中的《金匮玉函经二注》实为周扬俊著，不是程林作品，不能错配。
   - 《金匮》仍保留徐彬、尤怡、陈修园三家，满足范围要求。
2. 叶霖《增订温病条辨》延期。
   - Wikisource未发现全文；暂不采用来源和再分发许可不明的网络转录。
   - 首版已有两种吴瑭之后的扩展和两种清楚标记的前导源流。

如果后续找到许可、底本和质量均合格的版本，可以通过语料版本升级加入，不阻塞首版。

## 5. 许可初步结论

抽查Wikisource页面显示：

- 站点文字按“知识共享 署名-相同方式共享 4.0”提供，附加条款可能适用；
- 多个古籍页带 `PD-old` 标记；
- 最终发布包需要在 `NOTICE.md` 和 `source-manifest.json` 中保留页面链接、修订号、访问日期、署名和CC BY-SA 4.0说明；
- 仍要逐页检查特殊许可模板，不能仅凭站点总页脚推定每个影像文件的许可；
- 只抓取和转换文字，不把受不同许可约束的扫描影像打包进Skill。

## 6. Phase 1 前的硬门槛

每种入选作品必须完成：

1. 固定根页和全部实际使用子页的修订号；
2. 生成繁体原始快照及SHA-256；
3. 记录篇/卷预期清单并核对缺卷；
4. 检测替换字符、私用区字符、明显乱码、残留模板和伪标签；
5. 标记经文、注文、校语、按语的说话者；
6. 生成简体阅读本，但保留繁体快照用于审计；
7. 对高频名篇、方剂和随机段落进行抽样对照；
8. 通过后才写入最终 `source-lock.json`。
