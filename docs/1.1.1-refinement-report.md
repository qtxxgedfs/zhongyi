# 1.1.1 范围可信与材料组织精修报告

日期：2026-09-20。按确认方案实施P0/P1/P2，不调整原始文本、不重切语料、不更换检索架构。

## 1. 反馈验证与根因

1.1.0中直接询问“成无己如何解释桂枝汤”，返回《伤寒论》及喻昌、尤怡，并标记 `conflict=true`；加 `--author 成无己` 才返回 `COMMENTARY-SHANGHAN-CHENGWUJI-000118`。

根因有两条：

- 查询扩展的代表段落 `SHL-000054` 被用作范围判断条件；医家注书不可能包含这个原典ID，因此准确结果被全库回退覆盖。
- “原文/怎么说”优先触发原句模式，随后无条件要求命中原典层。只禁用代表段落分支，带“原文”的医家问题仍会出错。

另发现重复别名产生作者与作品的错误交集；完整注书名被内部原典名截获；引文转引先占名额后被研究包删除；固定A/B预算可能丢掉主段落且错误称为未检得。

## 2. 实施内容

### P0：范围与回退

- 代表段落只参与排序，不参与是否放弃指定范围的判定。
- 先识别指定医家/注书，再识别原句任务；医家注文的“原文”不要求原典命中。
- 先完成范围内精确与必要的宽松召回；指定范围已有直接支持时保留范围。
- “只看/只查/只在”、排除对象、CLI显式过滤与 `--no-route-fallback` 不越界。
- 一般范围题将范围外材料放入 `alternative_results` / `source_alternatives`；不覆盖指定医家结果。
- 出处核对问法可在披露后软回退。提示只陈述检索事实；`conflict_detected` 不等于证明读者记错。
- 对指定原典的原句核对，关联注书命中不能代替原典自身的依据。

### P1：查询与研究包

- 医家别名归并为明确作品集合，多位医家按集合并集召回；完整注书名优先于内嵌原典名。
- 比较按对象补充索引候选、预留代表材料；三位医家可使用三条医家名额，总条数仍受 `--limit-total` 限制。
- `scope_coverage` 区分 `matched`、`not-found`、`not-displayed`、`not-displayed-budget`；缺项不得宣称比较完整。
- 查询扩展保留引号原句、关注点和比较双方；补充禁忌、啜粥等关注点规则，不仅检索方剂名。
- 纯经文转引在分配医家名额前排除，允许实际注文补选；显式上下文保留转引，并标注其性质。
- A/B共用字符预算，主材料优先于范围外备选；全文不截断、不改写。
- 上下文先装入锚点，再考虑邻段；锚点超预算时明确说明，主ID为空，不用邻段替代。
- 预算遗漏列出ID和字符数；最终展示计数、引用白名单和比较覆盖以实际研究包重新核对。
- `core_quote` 和起止位置与数据库连续子串一致。

### P2：展示和文档

- 确定性Markdown/HTML标为材料预览，不把通用提示冒充本题主旨。
- 省略空A/B层；缺少原典层不写成原典不存在。
- 关系标签中文化；HTML来源信息收拢；转引经文不冒充医家观点。
- 更新Skill、回答协议、用户手册、安装说明、README、CHANGELOG与VERSION。
- 运行时自检新增不提供人工terms的成无己原文查询。
