# 现代医学证据规则

## 触发级别

- M0 纯文献：字词、原句、篇章、版本；一般不输出强行类比。
- M1 概念对照：解释古今概念边界及能否对应。
- M2 证据/安全：疾病、症状、方药、疗效、不良反应、检查、预后；默认完整输出现代层。
- M3 急症：先按安全规则分流，再讨论文献。

## 来源优先级

1. 卫生主管部门、药监机构、WHO、CDC、NICE等官方资料；
2. 正式临床指南和专业学会共识；
3. Cochrane及其他可核验的系统综述、Meta分析；
4. 随机对照试验；
5. 观察性研究；
6. 动物、细胞与机制研究，仅作为低直接性背景。

商业宣传页、无作者日期网页、搜索摘要和单一新闻报道不得作为疗效依据。

## 输出要求

每项结论记录机构/作者、标题、日期、URL、DOI/PMID（如有）和在线核验日期，并说明直接性、证据类型、可信度及局限。主动呈现阴性、不一致或低质量证据。

断网时立即继续原典和医家层；可以使用尚在有效期内且 `citation_recommended=true` 的本地缓存，否则说明无法联网核验，不以模型记忆填补现代结论。

## 运行时工具

单次调用优先使用：

```bash
python scripts/modern_evidence.py assess --query "用户问题"
```

返回分类、缓存命中和去身份化网页检索计划。M3 的 `safety_message` 必须先于检索输出；请求“最新/当前指南”时即使缓存有效也要联网更新。缓存状态和来源域名检查：

```bash
python scripts/modern_evidence.py status
python scripts/modern_evidence.py source-check --url "https://..."
```

首批缓存仅覆盖24个主题中的6条已核验记录，主要包括中药总体证据与产品安全、针灸疼痛证据与操作安全、卒中警示和严重过敏。缓存没有覆盖具体方剂、剂量或大多数疾病，绝不能把总体结论外推到具体产品和个人。

完整网页接入及失败降级见 `workbuddy-web-evidence.md`。
